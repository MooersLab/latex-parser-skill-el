Turn unstructured text in an Emacs LaTeX buffer into a structured LaTeX fragment with the transcript-parser skill.
This skill was originally developed to parse prose extracted from audio files on a digital voice recorder, hence the name transcript-parser.
We extracted this functionality from the whisper-dvr.el package to make it available for any chunk of prose in  \LaTeX, regardless of its origin.

We wanted to break out this capability because the whisper-dvr.el package depends on the whisper.el package which is turn is not in MELPA.
This means that whisper-dvr.el cannot be in MELPA

This package runs the text through an LLM.
That LLM can be a frontier model or a local model.


* What it does
#+INDEX: overview

Select a transcript in a LaTeX buffer and press one key.
The package returns a fragment with one =\subsubsection= per topic, =\index= keys below each heading, one sentence per line, expanded contractions, no sound descriptions such as =(coughing)=, and a closing checklist of TODO items.
It works on the active region, the whole buffer or its document body, or a file on disk.

The work runs in four stages.

#+ATTR_LATEX: :booktabs t
#+CAPTION: The four stages of the pipeline.
| Stage | Name         | Kind          | What it does                                                |
|-------+--------------+---------------+-------------------------------------------------------------|
|     1 | Replacements | Deterministic | Expands contractions and applies your dictation rule files  |
|     2 | Parse        | Model         | Sends the skill instructions and the text to the backend     |
|     3 | Verify       | Deterministic | Checks the reply against the rules of the skill              |
|     4 | Repair       | Model         | Sends the list of violations back for a corrective pass      |

Stage 1 is self-contained and needs no other package.
The model can be Claude Code, the Claude API, a local server such as Ollama, or anything set up in gptel.

* Requirements
#+INDEX: requirements

- Emacs 28.1 or later.
- One of the following for the model stages.
  - Claude Code, signed in, for the default =claude-code= backend.
  - A Claude API key for =anthropic-api=.
  - A local chat completions server such as Ollama, llama.cpp, LM Studio or vLLM for =openai-compatible=.
  - The gptel package for =gptel=.
- AUCTeX is optional.

* Installation
#+INDEX: installation

Install from MELPA using the following form.

#+begin_src emacs-lisp
(use-package latex-parser-skill
  :ensure t
  :defer t
  :init
  (with-eval-after-load 'tex
    (define-key LaTeX-mode-map (kbd "C-c t") 'latex-parser-skill-command-map))
  (with-eval-after-load 'tex-mode
    (define-key latex-mode-map (kbd "C-c t") 'latex-parser-skill-command-map)))
#+end_src

Install from a clone with the following form. Edit the path to customize where you cloned the package.

#+begin_src emacs-lisp
(add-to-list 'load-path "~/6112MooersLabGitHubLabRepos/latex-parser-skill-el")
(require 'latex-parser-skill)
#+end_src

* Quick start
#+INDEX: quick start

1. Open a =.tex= file and press =C-c t p= to add the preamble lines the output needs.
2. Paste a transcript into the document body and select it.
3. Press =C-c t r=.
4. Review the result in the preview buffer and press =C-c C-c= to accept or =C-c C-k= to reject.
5. Press =C-c t v= at any time to check a buffer against the rules.

To parse a file without opening it, press =C-c t f=.
The result goes to =NAME_parsed.tex= beside the file.

The full walk-through is in [[file:docs/tutorial.org][docs/tutorial.org]].

* Suggested key bindings
#+INDEX: key bindings

The package binds no keys by itself.
Bind the prefix map under =C-c t= as shown above.

#+ATTR_LATEX: :booktabs t
#+CAPTION: Commands under the suggested =C-c t= prefix.
| Key       | Command                              | Purpose                                     |
|-----------+--------------------------------------+---------------------------------------------|
| =C-c t r= | =latex-parser-skill-region=          | Parse the active region                     |
| =C-c t b= | =latex-parser-skill-buffer=          | Parse the buffer or its document body       |
| =C-c t f= | =latex-parser-skill-file=            | Parse a file and write =NAME_parsed.tex=    |
| =C-c t d= | =latex-parser-skill-dwim=            | Region when active, otherwise buffer        |
| =C-c t v= | =latex-parser-skill-verify-buffer=   | Run the Stage 3 checks and show a report    |
| =C-c t s= | =latex-parser-skill-replace-region=  | Run Stage 1 alone on the region             |
| =C-c t p= | =latex-parser-skill-insert-preamble= | Insert the preamble lines the output needs  |
| =C-c t m= | =latex-parser-skill-select-backend=  | Switch the backend for this session         |
| =C-c t k= | =latex-parser-skill-cancel=          | Cancel the running job                      |
| =C-c t l= | =latex-parser-skill-show-log=        | Show the log buffer                         |
| =C-c t t= | =latex-parser-skill-menu=            | Open the transient menu                     |

More options, including the preview keys, are in [[file:docs/keybindings.org][docs/keybindings.org]].

* Choosing a backend
#+INDEX: backends

#+begin_src emacs-lisp
;; Claude Code (default).  nil uses the program's default model.
(setq latex-parser-skill-backend 'claude-code
      latex-parser-skill-claude-model nil)

;; Claude API.  The key comes from auth-source (host api.anthropic.com)
;; or from the ANTHROPIC_API_KEY environment variable.
(setq latex-parser-skill-backend 'anthropic-api)

;; A local model served by Ollama.
(setq latex-parser-skill-backend 'openai-compatible
      latex-parser-skill-openai-url "http://localhost:11434/v1/chat/completions"
      latex-parser-skill-openai-model "your-model-tag")

;; Whatever gptel is set up to use.
(setq latex-parser-skill-backend 'gptel)
#+end_src

Long input is split at blank lines for local models, and the parsed chunks are merged with one TODO block at the end.
Adjust the limit with =latex-parser-skill-chunk-sizes=.

* Your own dictation rules
#+INDEX: rule files

Add CSV files of =trigger,replacement= lines to Stage 1.
Triggers may hold several words.

#+begin_src emacs-lisp
(setq latex-parser-skill-replacement-files '("~/dictation/rules.csv"))
#+end_src

An external program can replace the built-in engine through =latex-parser-skill-replacement-command=.

* Privacy
#+INDEX: privacy

The package asks once per session before a backend sends text off the computer, and it asks before sending very large requests.
Use a local model for unpublished data and for anything covered by a data use agreement.
